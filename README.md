# dsh-find：在旧对话里找东西

把 DeepSeek Harness（DSH）想成一柜子的笔记本：**工作区**像书架，**对话**像一本本笔记。忘了在哪本笔记里聊过「旅行计划」，或者找不到 AI 给你的表格？不用一页页翻，打开 dsh-find 就能找。

**这个插件是怎么做的？** 0.3.11 及更早的版本使用 **DeepSeek** 制作；从 0.4.0 起（含 0.4.0）使用 **GPT** 制作。这说的是开发插件时用的模型。你用面板找东西时，插件只读本地对话记录，不调用 AI，也不消耗 token。

## 30 秒上手

1. 在 DSH 里按 **Ctrl+F**（Mac 上按 **⌘F**）。如果你已经选中一段文字，面板会先把它填进去。
2. 输入记得的几个字，例如「旅行计划」。按 **Enter** 或点 **查找**。只打字不会开始搜索。
3. 找到想看的结果，点一下就跳回原对话里的那段话。按 **Esc** 或点面板外可以关闭。

也可以在对话输入框里发送 `/find-text-ui 旅行计划`，直接打开面板并搜索，不用请 AI 帮忙。

## 我该点哪个标签？

| 你想找什么 | 点这里 | 会看到什么 |
| --- | --- | --- |
| 以前说过的一句话 | **文本** | 左边是已记录的「思考链」，右边是你说的话、AI 回复、工具输出和系统消息。关键词会高亮。 |
| 一张图或一段视频 | **图片/视频** | 先选工作区，再选对话。点缩略图可以放大，视频可以播放。 |
| 一份文档、表格或其他文件 | **文件** | 先选工作区，再选对话，按文件名找。默认也列出图片和视频；只想看其他文件就勾 **隐藏图片/视频**。 |

### 几个好用的小按钮

- **只看用户或 AI**：在「图片/视频」或「文件」页，点灭不想看的来源。例如只想找 AI 给的文件，就点灭「用户」。「文本」页右栏还可以按「工具」和「系统」筛选。
- **隐藏已归档**：不想翻归档对话就勾上。归档里的文字默认仍能搜到；想从结果跳回对话，需要先取消归档。
- **一键展开 / 一键折叠 / 重新扫描**：「图片/视频」和「文件」页平时只读你点开的对话。一键展开会读取更多对话，可能稍慢；折叠不会清掉已读结果；想刷新列表时点重新扫描。
- **打开文件夹**：在「文件」页点文件名，Windows 上运行 DSH 的那台电脑会打开文件所在的文件夹。普通文件会被选中，附件会打开存储目录；如果文件移走了，会看到提示。
- **另存图片或视频**：在「图片/视频」页右键缩略图，选「另存为…」会保存一份副本。右键菜单也能定位文件；删除本地文件需要确认两次，对话附件不能删除。

## 为什么有时找不到？

这不是电脑里的全盘搜索。「文件」页只收录对话中实际上传的附件，以及有明确创建、交付或工具产出记录的文件。聊天里只是提到一个文件路径，或脚本生成了文件却没留下可识别的记录，它可能不会出现。单个对话最多列出 1000 个文件，超过会有提示。

如果只是想换个颜色，打开 **DSH 设置 → 查找**，可以选「跟随 DSH」「深色」或「浅色」。

## 安装到 DSH

1. 从 [GitHub](https://github.com/A-2788553793/dsh-find) 下载源码并解压，或在终端运行：

   ```bash
   git clone https://github.com/A-2788553793/dsh-find.git
   ```

2. 在 DSH 里用 `plugin_manager install_bundle` 安装，把刚下载的 `dsh-find` 文件夹作为安装路径。
3. 刷新 DSH 页面，再按 **Ctrl+F**（Mac 上按 **⌘F**）试一下。

如果已经装过并且需要重装，先用 `plugin_manager remove_bundle` 移除 `dsh-find`，再安装并刷新。
